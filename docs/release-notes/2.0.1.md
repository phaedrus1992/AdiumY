> **Early preview — not a finished release.** 2.0.1 fixes a blocker in 2.0.0 and has still had limited testing on real machines. Expect rough edges, keep a backup of anything you care about, and report what breaks. The release page is marked pre-release for this reason.

2.0.1 is a patch on [2.0.0](https://github.com/phaedrus1992/AdiumY/releases/tag/v2.0.0). If you already installed 2.0.0, this is the one you want: **the first-run setup assistant was dead in 2.0.0**, so a fresh install went nowhere.

## What was wrong

The setup assistant appeared, but Continue and "Information About Importing" did nothing. No crash, nothing in the log. The window was on screen with no action target, because the window controller that owned it had already been deallocated.

The cause was `__attribute__((ns_consumes_self))`, an ownership annotation left over from before the fork. It did nothing while the code was MRC. The ARC migration made it real: ARC reads it as "release `self` when this method returns", so the controller was freed the moment the show method returned. The same annotation sat on 15 other methods, which is why Add Group and Add Contact from a link were dead too.

## What changed

- Every remaining `ns_consumes_self` annotation is gone.
- A window controller shown without an owner now holds itself until its window closes.
- Setup assistant, Add Group, and Add Contact from a link all work.

Nothing else in the app changed. The plan and the roadmap in the 2.0.0 notes still stand.

## Requirements

macOS 12 (Monterey) or later, Intel or Apple Silicon. Download the DMG, drag AdiumY to Applications, and launch. The build is Developer ID signed and notarized.
