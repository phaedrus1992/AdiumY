> **Early preview — not a finished release.** 2.0.0 is the fork's first release and has had limited testing on real machines. Expect rough edges, keep a backup of anything you care about, and report what breaks. The release page is marked pre-release for this reason.

AdiumY 2.0.0 is a fork of [Adium](https://github.com/adium/adium), the Cocoa/libpurple chat client for macOS. This is the first release under the AdiumY name, and it's the start of a plan to do the thing upstream stopped doing years ago: keep Adium shipping.

## The plan

Adium has been effectively unmaintained for a long while. The last releases shipped an updater pointed at a dead feed, protocols for servers that no longer exist, and a build that needed the maintainers' laptops to run. None of that is a knock on the people who built it — it's just what a decade of no releases looks like.

The fork has three jobs, roughly in order:

1. **Make it build and ship again.** Get to a reproducible, signed, notarized release anyone can cut. This is most of 2.0.0.
2. **Delete what's dead.** Dead protocols, dead services, dead plugins, dead migration code, dead build tooling. Also most of 2.0.0.
3. **Modernize what's left.** Bring the code and tooling up to current practice, then add back the things people actually miss. This is the part that continues past 2.0.0.

## What's migrated

- **Build and release.** The whole pipeline moved to CI. Push a `v*` tag and GitHub Actions builds it, Developer ID signs it, notarizes it, staples it, packages a DMG, signs the appcast, and cuts the release. It ran end-to-end for this release — the first repeatable release path the project has had in years.
- **Memory management.** The app is on ARC now. A couple of legacy files are still `-fno-objc-arc`; everything else is converted.
- **Toolchain.** Universal (Intel + Apple Silicon), built against a current SDK, macOS 12 (Monterey) minimum.
- **Identity.** Renamed throughout to AdiumY: app menu, About box, UI strings, the framework, the bundle IDs, the 15 file-type UTIs, the Spotlight importer, and the cache/log paths. Internal class names stayed `Adium*` on purpose — the nibs archive class names, so renaming them would break every nib.
- **XMPP.** A batch of modern XEPs: client state indication (0352), MUC bookmarks (0048), PEP bookmarks (0402), message styling (0393), delivery receipts (0184), chat markers (0333), and message carbons (0280).
- **Testing and quality gates.** The dead OCUnit harness is gone, replaced by a CoverageHost test project. CI runs a Clang static analyzer, semgrep SAST, a coverage ratchet, and clang-format.
- **Hardening.** A long sweep of real bugs: Bonjour/EZV file-transfer integrity (truncation, partial files, XML escaping, recursion caps), plugin uninstall teardown (uninstalled plugins used to leave menu items, preference panes, observers, and timers live), and libezv leaks.

## What isn't (yet)

- **Auto-update.** The feed URL and EdDSA public key are in the Info.plist, and CI publishes a signed appcast, so the plumbing is there — but the in-app updater is gone in 2.0.0. This build cannot check for or install updates. Bringing it back is [#128](https://github.com/phaedrus1992/AdiumY/issues/128), and it's first on the list.
- **Your Adium data.** There's no upgrade path from Adium ≤1.5. AdiumY uses the same `~/Library/Application Support/Adium 2.0` folder, but the one-time routines that converted old settings were removed, so an existing folder loads as-is with no conversion. Fresh installs are the supported case.
- **Dead protocols.** Gone: AIM/ICQ/OSCAR, MobileMe/.Mac, GTalk, LiveJournal, Gadu-Gadu, Novell/GroupWise, Sametime/Meanwhile, and Zephyr — plus the Twitter and Image Upload plugins and the video-chat scaffolding that never worked on macOS. 2.0.0 speaks XMPP (Jabber), IRC, and SIMPLE through libpurple.
- **Mac App Store.** Not a target. The app doesn't sandbox and needs library validation disabled; MAS forbids both. Distribution is a notarized direct download, which is also what auto-update needs.
- **The plugin/xtras system.** It still works, but it's the oldest thing left in the tree. Rethinking it around URL schemes and UTIs is [#153](https://github.com/phaedrus1992/AdiumY/issues/153).
- **Loose ends.** Help content still describes removed services ([#155](https://github.com/phaedrus1992/AdiumY/issues/155)), the icon is still the upstream duck ([#225](https://github.com/phaedrus1992/AdiumY/issues/225)), and a few tooling and audit items are open.

## Roadmap

- **2.0.x** — restore the auto-updater ([#128](https://github.com/phaedrus1992/AdiumY/issues/128)), turn on branch protection, and clean up what this release cycle turned up.
- **2.1.0** — test-infra and CI hardening (ASan/UBSan, warnings-as-errors, clang-tidy, zizmor), a closer look at the plugin/xtras structure, and more transports (Matrix, Meshtastic).
- **3.0.0** — a real transport layer beyond libpurple: RSS/Atom, ActivityPub, atproto/Bluesky, Slack, Discord.

## Requirements

macOS 12 (Monterey) or later, Intel or Apple Silicon. Download the DMG, drag AdiumY to Applications, and launch. The build is Developer ID signed and notarized.
