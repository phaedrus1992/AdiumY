AdiumY and Mac OS X sleep mode

How Mac OS X sleep mode affects AdiumY

Mac OS X automatically disconnects all network connections when you put your Macintosh to sleep. As a result, AdiumY can't stay connected to your accounts. AdiumY will automatically attempt to reconnect your accounts when the machine is awakened.

If AdiumY is not automatically reconnecting after the machine is awakened, check these items:

  • Do you have a network connection? You may have lost any AirPort connections if you are using a PowerBook which has moved since going to sleep.
  • Are you using the newest version of AdiumY? Recent versions have significantly improved reconnection upon awakening.
