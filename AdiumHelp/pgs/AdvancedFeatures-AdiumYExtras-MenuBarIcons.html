Menu bar icons

.AdiumYMenuBarIcons Xtras provide alternate menu bar icons for AdiumY.

Bundled dock icons

By default, AdiumY contains two menu bar icons that can be configured from AdiumY's Appearance preferences pane:

  • AdiumYy
  • AdiumYy Flashy

Installing dock icons

More menu bar icons are available at the AdiumYExtras website, and can be installed by clicking the install link on the Xtra's page. To install an .AdiumYMenuBarIcons file that you have already downloaded, simply doubleclick it. In either case, AdiumY will launch and put it into the correct place for you.

Creating a dock icon

Information on making custom menu bar icons is available at Creating menu bar icons.
