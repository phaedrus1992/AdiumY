Dock icons

.AdiumYIcon Xtras provide alternate dock icons for AdiumY.

Bundled dock icons

By default, AdiumY contains six dock icons that can be configured from AdiumY's Appearance preferences pane:

  • AdiumYy Black
  • AdiumYy Blue
  • AdiumYy Green
  • AdiumYy Purple
  • AdiumYy Red
  • AdiumYy Yellow

Installing dock icons

More dock icons are available at the AdiumYExtras website, and can be installed by clicking the install link on the Xtra's page. To install an .AdiumYIcon file that you have already downloaded, simply doubleclick it. In either case, AdiumY will launch and put it into the correct place for you.

Creating a dock icon

Information on making custom dock icons is available at Creating dock icons.
